# Sitio corporativo de transporte y logística
Abrir `index.html` en el navegador (o `npx serve` / extensión Live Server).
- `js/config.js`: nombre, logo, WhatsApp, textos, servicios, flota, galería, redes.
- `css/styles.css`: diseño y colores (variables `:root`).
- `css/animations.css`: keyframes, entrada de portada, scroll reveal, movimiento reducido.
- `js/main.js`: renderizado, carruseles, lightbox y formulario WhatsApp.
- `js/animations.js`: menú móvil, header, parallax, IntersectionObserver.
- `images/`: textura de papel y fotos (poner la ruta en el campo `img` de config).
